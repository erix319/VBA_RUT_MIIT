Вот пример простого теста на языке VBA, который содержит 50 вопросов по вычислению пределов функций и последовательностей. Код создаёт форму с вопросами, полями для ввода ответов, кнопками для проверки и навигации между вопросами. В конце выводятся правильные ответы.

1. Откройте Excel и нажмите ALT + F11, чтобы открыть редактор VBA.
2. Вставьте новый модуль, нажав Insert > Module.
3. Вставьте следующий код в модуль:

Option Explicit

Dim Questions(1 To 50) As String
Dim Answers(1 To 50) As Double
Dim UserAnswers(1 To 50) As Double
Dim CurrentQuestion As Integer

Sub CreateTest()
    ' Задаем вопросы и правильные ответы
    Questions(1) = "lim (x -> 0) (sin(x)/x)"
    Answers(1) = 1
    
    Questions(2) = "lim (x -> ∞) (1/x)"
    Answers(2) = 0

    ' Добавьте остальные вопросы и ответы здесь
    ' Пример:
    Questions(3) = "lim (x -> 0) (e^x - 1)/x"
    Answers(3) = 1
    
    ' ... (продолжайте до 50)

    ' Установите текущий вопрос
    CurrentQuestion = 1
    ShowQuestion
End Sub

Sub ShowQuestion()
    ' Отображение текущего вопроса и поля для ответа
    With UserForm1
        .LabelQuestion.Caption = Questions(CurrentQuestion)
        .TextBoxAnswer.Value = ""
        .LabelResult.Caption = ""
        .LabelCurrent.Caption = "Вопрос " & CurrentQuestion & " из 50"
        
        If CurrentQuestion = 1 Then
            .CommandButtonPrevious.Enabled = False
        Else
            .CommandButtonPrevious.Enabled = True
        End If
        
        If CurrentQuestion = 50 Then
            .CommandButtonNext.Enabled = False
        Else
            .CommandButtonNext.Enabled = True
        End If
        
        .Show
    End With
End Sub

Sub CheckAnswer()
    ' Проверка ответа пользователя
    Dim userAnswer As Double
    userAnswer = Val(UserForm1.TextBoxAnswer.Value)
    
    UserAnswers(CurrentQuestion) = userAnswer
    
    If userAnswer = Answers(CurrentQuestion) Then
        UserForm1.LabelResult.Caption = "Правильно!"
    Else
        UserForm1.LabelResult.Caption = "Неправильно! Правильный ответ: " & Answers(CurrentQuestion)
    End If
End Sub

Sub NextQuestion()
    If CurrentQuestion < 50 Then
        CurrentQuestion = CurrentQuestion + 1
        ShowQuestion
    End If
End Sub

Sub PreviousQuestion()
    If CurrentQuestion > 1 Then
        CurrentQuestion = CurrentQuestion - 1
        ShowQuestion
    End If
End Sub

Sub ShowResults()
    Dim result As String
    Dim i As Integer
    
    result = "Правильные ответы:" & vbCrLf
    
    For i = 1 To 50
        result = result & Questions(i) & " - " & Answers(i) & vbCrLf & _
                 "Ваш ответ: " & UserAnswers(i) & vbCrLf & vbCrLf
    Next i
    
    MsgBox result, vbInformation, "Результаты"
End Sub


4. Создайте форму UserForm1 и добавьте следующие элементы управления:
   – Label для отображения вопроса (назовите его LabelQuestion)
   – TextBox для ввода ответа (назовите его TextBoxAnswer)
   – Label для отображения результата проверки (назовите его LabelResult)
   – Label для отображения текущего вопроса (назовите его LabelCurrent)
   – CommandButton для проверки ответа (назовите его CommandButtonCheck, установите текст "Проверить" и свяжите с процедурой CheckAnswer)
   – CommandButton для следующего вопроса (назовите его CommandButtonNext, установите текст "Следующий" и свяжите с процедурой NextQuestion)
   – CommandButton для предыдущего вопроса (назовите его CommandButtonPrevious, установите текст "Предыдущий" и свяжите с процедурой PreviousQuestion)
   – CommandButton для показа результатов (назовите его CommandButtonResults, установите текст "Показать результаты" и свяжите с процедурой ShowResults)

5. Запустите тест, вызвав процедуру CreateTest.

Этот код создаёт простой тест, который можно расширять, добавляя больше вопросов и ответов. Не забудьте заполнить все 50 вопросов и их правильные ответы в массивы Questions и Answers.

Чтобы добавить систему оценки по пятибалльной шкале в конце теста, мы можем модифицировать код, добавив вычисление процента правильных ответов и выставление оценки. Вот как это можно сделать:

1. В конце процедуры ShowResults добавьте код для вычисления процента правильных ответов и присвоения оценки.

Вот обновлённый код с добавлением оценки:

Sub ShowResults()
    Dim result As String
    Dim i As Integer
    Dim correctCount As Integer
    Dim percentage As Double
    Dim grade As String
    
    ' Подсчёт количества правильных ответов
    correctCount = 0
    
    For i = 1 To 50
        If UserAnswers(i) = Answers(i) Then
            correctCount = correctCount + 1
        End If
    Next i
    
    ' Вычисление процента правильных ответов
    percentage = (correctCount / 50) * 100
    
    ' Присвоение оценки по пятибалльной шкале
    Select Case percentage
        Case Is >= 90
            grade = "5"
        Case Is >= 75
            grade = "4"
        Case Is >= 60
            grade = "3"
        Case Is >= 40
            grade = "2"
        Case Else
            grade = "1"
    End Select
    
    ' Формирование результата для отображения
    result = "Правильные ответы:" & vbCrLf
    
    For i = 1 To 50
        result = result & Questions(i) & " - " & Answers(i) & vbCrLf & _
                 "Ваш ответ: " & UserAnswers(i) & vbCrLf & vbCrLf
    Next i
    
    result = result & "Всего правильных ответов: " & correctCount & " из 50" & vbCrLf
    result = result & "Процент правильных ответов: " & Format(percentage, "0.00") & "%" & vbCrLf
    result = result & "Ваша оценка: " & grade
    
    MsgBox result, vbInformation, "Результаты"
End Sub


▎Объяснение изменений:

• Подсчёт правильных ответов: Мы используем переменную correctCount, чтобы подсчитать количество правильных ответов.
• Вычисление процента: Процент правильных ответов вычисляется как отношение количества правильных ответов к общему количеству вопросов (50), умноженное на 100.
• Присвоение оценки: Используется конструкция Select Case, чтобы присвоить оценку в зависимости от процента правильных ответов:
  – 90% и выше — оценка 5
  – 75% до 89% — оценка 4
  – 60% до 74% — оценка 3
  – 40% до 59% — оценка 2
  – Менее 40% — оценка 1

Теперь, когда пользователь завершит тест и нажмёт кнопку для показа результатов, он увидит свои ответы, количество правильных ответов, процент правильных ответов и итоговую оценку.
